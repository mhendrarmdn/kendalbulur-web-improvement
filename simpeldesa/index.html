Akses Simpeldesa

Halaman informasi sebelum warga diarahkan ke platform layanan resmi.

Fitur Usulan

Akses layanan digital tanpa integrasi rumit

Simpeldesa dapat dijelaskan sebagai kanal pelayanan digital. Website Kendalbulur cukup menyediakan informasi, petunjuk, dan tombol yang mengarahkan warga ke platform resmi.

  • Tidak menyinkronkan database WordPress.
  • Tidak membuat login/SSO sendiri.
  • Tidak menggunakan API tanpa akses resmi penyedia.
  • URL tenant/layanan khusus Kendalbulur perlu divalidasi operator.
