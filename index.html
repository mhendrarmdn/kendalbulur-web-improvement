Prototype KKM • Website Desa

Kendalbulur yang lebih informatif, rapi, dan mudah digunakan.

Prototype ini merangkum perbaikan utama hasil audit dan wawancara operator: transparansi APBDes, akses Simpeldesa, direktori RT/RW, Potensi Desa, arsip regulasi, konsistensi konten, serta UI yang lebih proporsional.

Prioritas Pengembangan

Enam pekerjaan utama hasil wawancara operator

Fokus dibuat realistis untuk masa KKM dan tetap mudah diteruskan oleh operator WordPress setelah pendampingan.

01

APBDes Interaktif

Ringkasan anggaran, grafik, progress realisasi, tabel rinci, filter tahun, dan unduh PDF.
02

Akses Simpeldesa

Landing informasi singkat dan tombol menuju layanan resmi tanpa membuat integrasi API.
03

Direktori RT/RW

Template kartu interaktif untuk foto, nama, jabatan, wilayah, dan kontak yang disetujui.
04

Potensi Desa

Wisata, pertanian, perikanan, UMKM, budaya, dan BUMDes dalam kategori yang mudah dipahami.
05

Arsip Regulasi

Perdes, Perkades, dan SK dengan metadata yang lebih rapi, status validasi, dan tautan dokumen.
06

UI/UX & Konten

Perbaikan proporsi, link rusak, halaman kosong, Lorem Ipsum, statistik tidak konsisten, dan responsivitas.

Prinsip Implementasi

Satu prototype, dua jalur deployment

Vercel

  • Static HTML/CSS/JS tanpa build process
  • Deploy langsung dari GitHub
  • Mudah dipreview tim sebelum menyentuh website produksi
  • Setiap halaman memiliki URL sendiri

WordPress / Elementor

  • Section dapat dipindah ke HTML Widget Elementor
  • CSS global dapat ditempatkan di Additional CSS / Elementor Custom CSS
  • Link PDF menggunakan Media Library WordPress
  • Konten RT/RW dan Potensi Desa dapat dikelola operator
