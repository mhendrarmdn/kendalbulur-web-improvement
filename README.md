# Kendalbulur Web Improvement

Prototype peningkatan website Desa Kendalbulur untuk KKM.

## Branch

- `main` — prototype modular awal.
- `prototype/full-site-replica` — **re-engineering front-end penuh** yang mempertahankan tampilan/struktur Kendalbulur dan menambahkan fitur usulan operator.

## Scope replica

- Beranda
- Profil Umum
- Sejarah Desa
- Wilayah Desa
- Peta Desa
- SOTK
- Profil Kepala Desa
- IDM
- BPD
- Lembaga Adat Desa
- BUMDesa
- KDMP
- PKK
- RT/RW
- Satlinmas
- Posyandu
- Karang Taruna
- Forum Anak Desa
- Perdes
- Perkades
- SK
- Agenda
- APBDes
- Realisasi APBDes
- Simpeldesa
- Warta Desa
- Potensi Desa

## Fitur usulan

1. Dashboard APBDes interaktif.
2. Laporan realisasi dalam tabel + progress.
3. Link PDF Anggaran dan Realisasi.
4. Landing/redirect Simpeldesa tanpa API.
5. Direktori RT/RW dengan flip card.
6. Katalog Potensi Desa.
7. Template lembaga dan regulasi yang konsisten.

## Data

Jangan menganggap seluruh angka sebagai data final. Angka APBDes 2026 pada prototype ditranskripsi dari infografis yang terlihat pada situs/screenshot dan harus diverifikasi terhadap dokumen resmi. Data realisasi dan biodata RT/RW sengaja belum dibuat fiktif.
